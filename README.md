# Redis Lesson

Конспект курса **«Изучение Redis с нуля»** по видеокурсу Гоши Дударя / itProger.

Материал оформлен по принципу предоставленного Docker-конспекта:
- каждый урок находится в отдельной папке;
- `lesson.md` содержит понятную теорию, команды и практику;
- `commands.md` содержит короткую шпаргалку команд там, где это полезно;
- в конце курса есть общий список тем.

## Уроки

| Урок | Тема |
|---|---|
| 1 | Что такое Redis? Установка и настройка |
| 2 | Основы работы с Redis |
| 3 | Продвинутые структуры данных |
| 4 | TTL, Expire, Pub/Sub и транзакции |
| 5 | Подключение Redis к Python |
| 6 | Кеширование с Redis |
| 7 | Проект на Python + Redis |
| 8 | Итоги курса |

## Источник

Курс состоит из 8 уроков. Темы и порядок уроков сверены с официальными страницами курса itProger.


## С чего начать

1. Установить Redis или запустить Redis через Docker.
2. Проверить подключение.
3. Пройти уроки по порядку.
4. После каждого урока выполнить практику.
5. Для Python установить библиотеку `redis`.
6. В конце собрать небольшой проект с Redis.
