# Урок 4. TTL, Expire, Pub/Sub и транзакции

Видео: https://itproger.com/course/redis/4

В уроке рассматриваются время жизни ключей, система публикации сообщений и транзакции.

## TTL

TTL — Time To Live, то есть оставшееся время жизни ключа.

Создать ключ:

```redis
SET code "123456"
```

Установить время жизни 60 секунд:

```redis
EXPIRE code 60
```

Проверить оставшееся время:

```redis
TTL code
```

Если ключ существует и имеет срок жизни, Redis возвращает количество секунд.

Если TTL не установлен:

```text
-1
```

Если ключ уже не существует:

```text
-2
```

## SET с временем жизни

Можно сразу установить значение и срок:

```redis
SET code "123456" EX 60
```

## PERSIST

Удаляет ограничение по времени:

```redis
PERSIST code
```

После этого ключ снова становится бессрочным.

## Pub/Sub

Pub/Sub позволяет одному процессу отправлять сообщения, а другим — получать их.

Подписка:

```redis
SUBSCRIBE news
```

В другом терминале:

```redis
PUBLISH news "Hello!"
```

Подписчик получит сообщение.

Отписка:

```redis
UNSUBSCRIBE news
```

Типичная схема:

```text
Publisher
   ↓
 channel
   ↓
Subscriber
```

Pub/Sub полезен для real-time уведомлений, статусов и сообщений между компонентами приложения.

## Транзакции

Redis позволяет объединять команды с помощью:

```redis
MULTI
```

Команды после `MULTI` ставятся в очередь.

Завершение:

```redis
EXEC
```

Пример:

```redis
MULTI
SET balance 100
INCRBY balance 50
EXEC
```

## Практика

Создать временный код:

```redis
SET verification:123 "654321" EX 120
TTL verification:123
```

Создать канал:

```redis
SUBSCRIBE notifications
```

Во втором терминале:

```redis
PUBLISH notifications "Новая задача"
```

## Кратко

```text
EXPIRE      установить срок жизни
TTL         узнать оставшееся время
PERSIST     убрать срок жизни
SUBSCRIBE   подписаться на канал
PUBLISH     отправить сообщение
UNSUBSCRIBE отписаться
MULTI       начать транзакцию
EXEC        выполнить очередь команд
```
