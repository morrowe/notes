# Урок 8. Заключительная часть Redis

Видео: https://itproger.com/course/redis/8

Последний урок — повторение материала и направление для дальнейшего изучения.

## Что изучено

### 1. Основы Redis

Redis — быстрое хранилище данных в памяти.

Основная модель:

```text
key → value
```

### 2. Строки

```redis
SET
GET
DEL
EXISTS
INCR
DECR
```

### 3. Структуры

```text
Set
Sorted Set
List
Hash
HyperLogLog
```

### 4. TTL

```redis
EXPIRE
TTL
PERSIST
```

### 5. Pub/Sub

```redis
SUBSCRIBE
PUBLISH
UNSUBSCRIBE
```

### 6. Транзакции

```redis
MULTI
EXEC
```

### 7. Python

Для подключения:

```bash
pip install redis
```

Далее:

```python
import redis
```

### 8. Кеширование

Redis можно использовать для временного хранения часто запрашиваемых данных.

### 9. Проект

В финальном практическом примере Redis связывается с Python-приложением и используется для очереди задач и передачи статусов.

## Главное, что нужно запомнить

Redis — это не просто «еще одна база».

Он особенно полезен, когда нужны:

- очень быстрый доступ к данным;
- временное хранение;
- кеширование;
- очереди;
- обмен сообщениями;
- real-time взаимодействие.

Курс состоит из 8 уроков: от установки Redis и базовых команд до Python, кеширования и небольшого проекта.
