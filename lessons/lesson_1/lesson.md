# Урок 1. Что такое Redis? Установка и настройка

Видео: https://youtu.be/7Stle5LJoRA

Redis — это быстрое хранилище данных, которое работает в памяти и используется для хранения и быстрого получения данных.

Главная модель Redis — **ключ → значение**.

Пример:

```text
user:1:name → User
```

Здесь `user:1:name` — ключ, а `User` — значение.

## Зачем нужен Redis

Redis часто используют:

- для кеширования;
- хранения сессий;
- быстрых счетчиков;
- очередей;
- обмена сообщениями через Pub/Sub;
- временных данных;
- real-time приложений.

Redis особенно полезен там, где данные нужно получать очень быстро.

## Redis и обычная база данных

Обычная реляционная БД, например PostgreSQL, обычно хранит данные на диске и предоставляет SQL.

Redis работает как высокоскоростное хранилище в памяти и использует собственные структуры данных и команды.

Redis не обязательно заменяет PostgreSQL. Часто они используются вместе:

```text
Приложение
   ↓
Redis ← быстрые / временные данные
   ↓
PostgreSQL ← постоянные данные
```

## Установка

Redis можно установить локально или запустить в Docker.

Для Docker:

```bash
docker run --name redis -p 6379:6379 -d redis
```

Проверка контейнера:

```bash
docker ps
```

Подключение к Redis CLI:

```bash
docker exec -it redis redis-cli
```

После этого появится консоль Redis.

Проверка:

```redis
PING
```

Ответ:

```text
PONG
```

## Порт

Стандартный порт Redis:

```text
6379
```

Поэтому локальное подключение обычно выглядит так:

```text
host: localhost
port: 6379
```

## Практика

1. Запустить Redis.
2. Открыть `redis-cli`.
3. Выполнить `PING`.
4. Убедиться, что Redis отвечает `PONG`.
5. Выполнить `INFO` и посмотреть информацию о сервере.

## Кратко

- Redis — быстрое хранилище данных в памяти.
- Основная модель — ключ → значение.
- Стандартный порт — `6379`.
- Для проверки соединения используется `PING`.
- Ответ `PONG` означает, что сервер доступен.
